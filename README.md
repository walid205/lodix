# مشروع تطبيق LODIX لمشاهدة الأفلام المترجمة (جاهز للتحويل إلى APK عبر GitHub)

يحتوي هذا المجلد على الكود الكامل لتطبيق **LODIX** باللون الأسود والبنفسجي، مهيأ بالكامل للتحويل التلقائي إلى ملف أندرويد **APK** قابل للتثبيت على الهواتف الذكية باستخدام **GitHub Actions** و **Capacitor**.

---

## المحتويات داخل هذا الملف المضغوط:
1. **www/index.html** : النسخة الكاملة لتطبيق Lodix مع جميع الأفلام والروابط والترجمات العربية.
2. **www/manifest.json** : إعدادات تطبيق الويب التقدمي (PWA) والأيقونة.
3. **package.json** : مكتبات Capacitor الرسمية لبناء حزمة الأندرويد.
4. **capacitor.config.json** : إعدادات اسم التطبيق (Lodix) ومعرف الحزمة (com.lodix.movies).
5. **.github/workflows/build-apk.yml** : ملف التشغيل التلقائي على GitHub لبناء ملف APK في السحابة مجاناً.

---

## خطوات رفع الملفات على GitHub وتحميل ملف الـ APK:

### الخطوة 1: فك الضغط
قم بفك ضغط ملف **lodix-github-apk.zip** في مجلد على جهازك (تأكد من إظهار الملفات المخفية حتى يظهر مجلد **.github**).

### الخطوة 2: إنشاء مستودع جديد على GitHub
1. ادخل إلى حسابك في موقع GitHub وأنشئ مستودعاً جديداً (New Repository) باسم **lodix-app**.
2. ارفع جميع الملفات والمجلدات الموجودة داخل المجلد المفكوك إلى المستودع ثم اضغط **Commit changes**.

### الخطوة 3: استخراج وتحميل ملف الـ APK
1. بعد رفع الملفات، اضغط على تبويب **Actions** في أعلى مستودعك على GitHub.
2. ستجد عملية بناء باسم **Build Lodix Android APK** تعمل تلقائياً (تستغرق حوالي دقيقتين).
3. عند اكتمالها باللون الأخضر، اضغط عليها ثم انزل إلى قسم **Artifacts** في الأسفل.
4. اضغط على **Lodix-Android-APK** لتحميل ملف الـ **APK** النهائي وتثبيته مباشرة على هاتفك!
